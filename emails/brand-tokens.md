# Dr. Foy Email Brand Tokens

Quick reference when editing templates in Brevo or locally.

## Colors

| Token | Hex | Use |
|-------|-----|-----|
| Background | `#0E1318` | Email outer background |
| Surface | `#1B232C` | Cards, detail blocks |
| Surface raised | `#242E38` | Nested panels |
| Ink | `#F2E8DC` | Primary text |
| Muted | `#93A8B8` | Secondary text, footer |
| Teal | `#2DBFB1` | Eyebrows, links, accents |
| Coral | `#D9654A` | Wordmark |
| Border | `rgba(45, 191, 177, 0.22)` | Dividers |

## Typography

| Role | Font stack |
|------|------------|
| Wordmark | `'Ephesis', Georgia, 'Times New Roman', serif` (italic fallback) |
| Eyebrow / labels | `'Space Grotesk', Arial, Helvetica, sans-serif` |
| Headings | `'Cormorant Garamond', Georgia, 'Times New Roman', serif` |
| Body | `'DM Sans', Arial, Helvetica, sans-serif` |

### Eyebrow style

- Uppercase, letter-spacing `0.28em`, font-size `11px`, color `#2DBFB1`

### Heading style

- Font-size `32px` (hero) or `24px` (section), line-height `1.1`, color `#F2E8DC`

### Body style

- Font-size `16px`, line-height `1.65`, color `#F2E8DC`
